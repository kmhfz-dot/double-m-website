DOUBLE M WEBSITE - GITHUB PAGES UPDATE

1. Open your existing local GitHub repository folder for double-m-website.
2. Copy index.html from this package into the repository root, replacing the old index.html.
3. Copy the entire images folder into the same repository root.
4. Your repo should contain:
   .gitattributes
   index.html
   images/
5. Open GitHub Desktop.
6. Commit the changes to main.
7. Push origin.
8. Wait around 30-90 seconds for GitHub Pages to rebuild, then refresh your live site.

360 VIEWER
The website uses Pannellum from jsDelivr to render the Interior and Exterior 360 panoramas. Visitors need internet access for the viewer library to load.

IMPORTANT
The current portfolio and 360 imagery is illustrative concept imagery generated for presentation. It is labeled accordingly on the site so it is not represented as photography of completed Double M projects.
