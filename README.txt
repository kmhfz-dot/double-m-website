HOW TO INSTALL
1. Extract this ZIP.
2. In GitHub Desktop select your double-m-website repository.
3. Click Repository > Show in Explorer.
4. Copy EVERYTHING inside this extracted folder into that repository folder.
5. Choose Replace when Windows asks about index.html / images.
6. Do NOT delete your existing .gitattributes file.
7. In GitHub Desktop, Summary: Double M Gallery V3
8. Click Commit to main.
9. Click Push origin.
10. Wait 30–90 seconds and hard refresh the live site with Ctrl + F5.
